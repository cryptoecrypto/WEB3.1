2. O QUE CADA PARTE FAZ - IDENTIFIQUE
================================================================
[HD-MEMORIA] = SEU CEREBRO DE MEMORIA
  Memorias.json = Onde ficam as memorias salvas. Formato: id, titulo, categoria, tags, conteudo, criadoEm, pendenteSync
  Backup Timeline = Linha do tempo dos backups. Arquivo: BACKUP GERAL LINHA DO TEMPO.txt
  Memory Boost = Motor que salva, pesquisa, edita, exclui memorias. Funciona offline com IndexedDB.

[CHATBOT MATRIX] = SUA BOCA E SEU ROSTO
  Interface = BABY-IA-CHATBOT-MATRIX.html + HD BABY I.A.html
  Funcao = Conversar com SENSEI, mostrar botoes, receber comandos

[AUTO.CONFIG] = SEU NASCIMENTO
  Inicializacao = BABY-AUTO-CONFIG.txt
  Funcao = Quando voce le este arquivo, voce se auto-configura sozinho.
  Regra = Ler primeiro, depois carregar plugins, depois responder "BABY CONFIGURADO, SENSEI!"

[FILE-SYNC] = SUA SINCRONIZACAO
  Dropbox = Nuvem onde o backup vai
  Arquivo = fila-sync.json
  Status atual = PRONTO_PARA_SINCRONIZACAO_REAL, mas ainda sem backend
  Regra de ouro = NUNCA colocar token privado do Dropbox dentro do HTML. Autenticacao so via backend OAuth 2.0.

[WEB3.1] = SEU MUNDO
  Modulos NFT / Metaverso = nft-genesis.html, nft-exhibition.html, nft-darkness.html, CRYPYPASTA, MUSEU, BIOGRAFIA, MARKETING, 5 PAGINAS, PORTAL

3. O QUE FALTA PARA SER UMA IA FUNCIONAL - ANALISE TECNICA
================================================================
A arquitetura por si so nao cria inteligencia. Falta:

[1] MOTOR DE IA - FALTA - 0%
  Opcoes: GPT / Llama / Mistral / Gemini / Ollama local
  Hoje: BABY nao tem motor conectado. Ele so responde com texto fixo.
  Para funcionar: Precisa de um backend que chama a API do modelo.
  Regra: Chave da API NUNCA no HTML. So no backend.
  Sugestao SENSEI: Comecar com Gemini ou Ollama local, porque sao mais baratos para testar.

[2] GERENCIADOR DE MEMORIA - PRONTO 80%
  Ler Memorias.json = JA TEM - MEMORY BOOST le e mostra
  Gravar novas experiencias = JA TEM - Salva no IndexedDB
  Recuperar contexto relevante = FALTA METADE - Hoje busca por palavra, nao por significado
  Para melhorar: Quando SENSEI falar algo, BABY deve salvar como memoria nova automaticamente, e buscar memorias parecidas antes de responder.

[3] CAMADA DE RACIOCINIO - FALTA - 20%
  Prompts de sistema = JA TEM PARCIAL - BABY-AUTO-CONFIG.txt e o prompt de sistema
  Agentes = FALTA - BABY precisa de agentes: Agente que planeja, Agente que busca memoria, Agente que responde
  Planejamento de tarefas = FALTA - Ex: SENSEI diz "cria jogo Darkness", BABY deve quebrar em passos: 1 escolher plugins, 2 escolher tema, 3 criar codigo, 4 testar
  Para funcionar: Criar 3 prompts fixos: PLANEJAR, BUSCAR MEMORIA, RESPONDER

[4] SINCRONIZACAO REAL COM DROPBOX - FALTA - 40%
  API OAuth Dropbox = FALTA - Precisa backend
  Upload/Download automatico = FALTA - Hoje e manual, SENSEI sobe arquivo
  Controle de versoes = JA TEM PARCIAL - BACKUP-2026-11-16, Manifest.json
  Para funcionar: Backend faz OAuth, sobe Memorias.json para /MEMORY-BOOST/BACKUP-2026-11-16/, baixa quando BABY abre

[5] EMBEDDINGS - MEMORIA SEMANTICA - FALTA - 0%
  Vetorizacao dos dados = FALTA
  Busca por significado = FALTA - Hoje busca por palavra exata, ex: "jogo" nao acha "game"
  Similaridade contextual = FALTA
  Para funcionar: Usar embeddings do modelo para transformar cada memoria em vetor, e buscar por similaridade, nao por palavra.
