# CRYPY BABY AGENT CORE.IA v13.0.0
Módulo independente para desenvolvimento e validação. Abra `BABY-AGENT-CONSOLE.html` em uma hospedagem que sirva os arquivos do repositório.

O núcleo faz leitura de caminhos declarados, interpretação de TXT/JSON, inventário, plano de ação, navegação permitida e limpeza apenas de CacheStorage próprio. Escrita/movimentação de arquivos, sincronização GitHub/Dropbox e envio de e-mail exigem backend autenticado.
